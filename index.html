Architecture

ETL Pipeline

Fully automated pipeline from raw simulation to dashboard with zero manual processing.

Step 01
Data Generation
Python simulation engine generates 50,000 realistic call records with configurable agent behavior and injected anomalies.
Step 02
Schema Design
Normalized MySQL schema with 3 relational tables...call_center_logs, agents, and categories, linked by foreign keys.
Step 03
MySQL Ingestion
SQLAlchemy ETL script loads all tables in dependency order with credential management via .env.
Step 04
KPI Analysis
17 SQL queries using JOINs, window functions, and subqueries extract AHT, FCR rate, SLA adherence, and agent utilization.
Step 05
Anomaly Detection
Z-score analysis on weekly Tech Support drop rates surfaces the injected +40% anomaly window automatically.
Step 06
Dashboard
Power BI dashboard with 6 KPI panels visualizes all metrics and highlights the anomaly for management-level review.
Anomaly Detection

Injected Incident Investigation

A deliberate anomaly was injected into the Tech Support data to simulate a real-world incident.

What was injected

During a 7-day window, the Tech Support drop rate was spiked from a baseline of ~5% to ~45%, a +40 percentage point increase. Eight agents were also assigned inflated call durations (1.8x normal) to simulate degraded performance.


How it was detected

Weekly drop rates were grouped and a z-score was calculated for each week. Any week with an absolute z-score above 2 was flagged as an anomaly. The injected week returned a z-score of ~2.79, successfully surfacing the incident. SQL rolling averages confirmed the sustained nature of the spike.
